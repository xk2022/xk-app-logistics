## 開發範圍

- 後端：UPMS 模組、帳號與固定角色、登入／登出／本人狀態、改密、受控初始化及復原，明確 DTO、交易、資料驗證、稽核與 Flyway migration。先定契約及最小資料模型，遵循公司標準。
- 認證：遵循[採用決策](../98_decisions/2026-11-25-m2-access.md)及[角色基準](../04_architecture/access-baseline.md)，同源 Session + CSRF；所有業務授權在後端執行。不得弱化已採用政策。
- 介面：登入、登出、本人狀態、強制改密流程、角色對應的基礎工作台、必要帳號管理介面；不開放尚未核准的操作權限。
- DEV／CI：沿用 M1 技術鎖版與品質流程、隔離合成測試資料、保留既有 health/status 與工程測試。
- 不實作 CRM、ADM、訂單、派工或照片功能，不變更原 OpenAPI 0.2.0 草稿契約，不部署。

## 完成條件

| 驗收 | 必要證據 |
| --- | --- |
| 初始化與資料庫 | 空庫 migration、受控初始化、無固定密碼；測試資料隔離 |
| 登入與帳號 | 正常登入／登出、拒絕未授權或停權帳號、受控復原及改密 |
| Session 與 CSRF | 閒置及絕對期限、並存限制、撤銷生效、合法寫入與未授權拒絕 |
| 密碼與角色 | 長度、不可逆安全儲存、限流、單一角色與伺服器端授權 |
| UI | 手機與桌面登入、錯誤、登出、改密及角色工作台 |
| CI | 前端品質、Maven verify、依賴及秘密檢查、Compose/E2E 全通過 |
