# M5 部署與環境隔離｜待實作
沿用[環境策略](environments.md)及[核准決策](../98_decisions/2026-11-27-m5-release.md)。

| 環境 | 用途 | 邊界 |
| --- | --- | --- |
| DEV | 本機與 CI | Docker／隔離 PostgreSQL、合成資料 |
| DEMO | 技術驗證 | 合成資料、獨立 DB/憑證、受限角色及可控重置 |
| STG | 客戶驗收 | 符合商業用途的已核准平台或獨立容器、獨立資源 |
| PRD | 正式營運 | 自架 Docker 或另行核准方案；維持啟動禁止 |

初期候選 Vercel／Render／Neon；部署前確認官方條款、免費限額、休眠、持久化、網域、費用及帳號。禁止用維持流量規避休眠、禁止自動付費升級。商業 Showcase 不使用僅供非商業技術驗證的方案；可先使用合成截圖及受控展示，實際互動入口須在適用方案可用後驗收。

驗證瀏覽器同源 HTTPS、可信代理、Secure Cookie／Session／CSRF、私有 DB 最小權限、照片私有持久化及重啟後可用性。保留 UPMS 單 instance 約束；未核准持久儲存策略不得宣稱完整遠端照片流程。配置不含真實 Secrets。以版本化工件部署，健康檢查及 smoke 成功才能切換；失敗停止並依備份與遷移相容性復原，不任意降級 DB。PRD 不設自動部署觸發。
