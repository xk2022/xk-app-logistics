# LG-M3-01 車輛管理｜Approved

日期：2026-11-25（Asia/Taipei）。使用者明確回覆「全部採用」，Q21–Q25 已核准。

| ID | 採用方案 |
| --- | --- |
| Q21 | UUID 主鍵、唯一車牌 |
| Q22 | 支援車頭、拖板及各類貨車 |
| Q23 | 可用、使用中、維修、停用四種業務顯示狀態 |
| Q24 | 車牌、車種、載重、車籍及檢驗期限 |
| Q25 | ADMIN、DISPATCHER 管理本公司車輛；DRIVER 後續僅能查看本人指派車輛 |

工程邊界：主檔可用／維修／停用與派工占用分開，「使用中」由後續 TMS 有效占用推導，不提供人工任意切換。此工作包沒有派工，故不可建立使用中假資料或開放司機全車隊查詢。車頭及拖板各自識別；是否獨立占用、合載、預約時窗、組合配對及釋放例外仍由 M3-04 核准，不因分類採用而定案。

車籍與檢驗資訊作記錄及提示，法定檢驗週期、證照適用性與自動派工阻擋條件另行核定。車種可配置分類及正式碼值仍需核對 ADM；不把合成值當正式核准名單。
