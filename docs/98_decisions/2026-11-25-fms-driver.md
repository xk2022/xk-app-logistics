# LG-M3-02 司機管理｜Approved

日期：2026-11-25（Asia/Taipei）。使用者明確回覆「全部採用」，Q26–Q30 已核准。

| ID | 採用方案 |
| --- | --- |
| Q26 | UUID 主鍵＋唯一司機編號 |
| Q27 | 司機主檔與 UPMS DRIVER 帳號可選擇性一對一關聯 |
| Q28 | 在職、停用、離職；出勤及任務占用獨立 |
| Q29 | 駕照類別、證照資訊及有效期限，先記錄與提示 |
| Q30 | ADMIN、DISPATCHER 管理司機；DRIVER 只讀本人資料 |

司機主檔不是登入帳號。未綁定仍可管理；綁定必須由有權限者操作、驗證目前角色為 DRIVER 且有效，唯一性在 DB 保護。不得自動創建帳號、升權或讓調度員取得 UPMS 帳號管理能力；帳號停用、改角色、撤銷或解綁後本人讀取不得繼續。是否需要跨模組變更帳號生命週期的額外規則另行審議。

在職與出勤只代表行政來源，不是實際可派工或法規資格。駕照類別、實際證件格式、證照保存／刪除期限、離職復職、工時、法定限制及任務占用政策仍待核准；不要求真實證件影像或身分證號。
