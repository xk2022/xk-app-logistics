# UI/UX 頁面規劃｜Draft

| 角色 | 頁面 |
| --- | --- |
| 共用 | 登入、本人帳號、錯誤及無權限頁 |
| 管理員 | M2：帳號、字典／參數、客戶、訂單工作台與草稿編輯；車輛／司機管理為後續 |
| 調度員 | M2：客戶、訂單列表、新增／編輯、項目／分段任務、完整性提示；派工看板、異常與結案為後續 |
| 司機 | M2：本人帳號及密碼；今日本人任務、明細、出發、回報、照片及歷史為後續（可見性待定） |

桌面調度工作台與行動司機介面分開適配；資料缺漏明示，API 失敗不得顯示假成功。先做首片草稿及列表，後續才開派工與回報。使用合成進口、出口、國內三類情境。

M2-05 的實作範圍見 [訂單工作台規格](order-workspace.md)：ADMIN／DISPATCHER 可使用列表、新增、完整編輯、項目／任務／依賴及只讀完整性。DRIVER 目前只有本人帳號與密碼頁，表中的本人任務與回報功能仍屬後續；正式受理、派車、照片及結案未開放。實測狀態見 [M2-05 驗證](../09_testing/m2-05-validation.md)。
