# TMS 調度工作台｜M3-05

ADMIN／DISPATCHER：分頁待派任務、當前派工、司機／主車／選用拖板選擇、明確指派確認、撤／改派原因、歷史與資源占用顯示。候選及衝突結果由伺服器提供；不能用前端隱藏繞過授權或將行政可用顯示為保證可派。依賴未就緒或無已核准組合時顯示阻擋原因。版本衝突、未知寫入結果及重送保留原次 key/body，不能自動覆寫。

DRIVER：手機本人有效任務唯讀、必要路線及作業資訊，撤／改派後重新讀取且不保留舊可見資料。無出發、回報、照片、任意司機查詢或整單入口。

桌機與手機提供載入／空狀態／錯誤／權限不足；使用合成資料，M3-04 的 API 完成且 CI 全過後才整合。

## 已凍結 API 的操作規則

管理端使用獨立七項 TMS API，維持分頁／搜尋的伺服器總數。每個任務以 generation 控制；assignment.version 是歷史轉態版本，不可替代 generation。改派候選帶目前 assignmentId，允許保留本次原有資源，但主車與拖板不可相同、完全相同資源不得當改派。阻擋前置的後段不能因撤派、時間經過或沒有占用而放行。UNCONFIRMED 顯示未核准；SYNTHETIC_TEST_ONLY 明示隔離工程驗收。

同時只保留一個不可變待確認命令，包含路徑、內容、key 與原 generation。傳送前確認；不自動換 key、採用 actualGeneration 或重新派工。網路／協定錯誤視為未知；403 CSRF_INVALID 僅更新 token，FORBIDDEN、401 或無法辨識的 403 清除敏感內容並重新登入。歷史重播收據證明原次成功，不能代表現在仍占用；下一操作須重新讀取當前狀態，讀取失敗不以收據補成可操作資料。

本人頁只讀 my-tasks 精確 14 欄，不讀 FMS 管理端／訂單端，不接受任意司機條件。刷新／切頁先清除舊頁；取消與請求序號防止舊回應回填。帳號切換以 account.id 重建元件；登出送出即卸載本人任務，若登出失敗須重新載入才顯示資料。
