# M4 手機司機與管理工作台｜設計基準
手機優先 RWD：本人任務列表→詳情→出發→進度及照片→異常／補件→完成確認／結果。顯示任務當前狀態、可操作按鈕、必要證據清單、上傳進度、失敗重試與版本衝突刷新；避免重送造成重複事件。不得提供別人任務查詢、不呈現多餘客戶個資。不要求行駛中操作，提示停妥後回報。
管理端延續既有調度工作台與訂單工作台，具異常待處理／補件歷程、完成與占用狀態、結案條件及阻擋理由。未核准政策以清楚禁用理由呈現，前端禁用不取代後端驗證。桌面與手機驗證使用合成資料。


## M4-03 管理異常處理

ADMIN／DISPATCHER 透過「異常處理」導覽，查詢待處理、待補件及已處置案例；DRIVER 不顯示管理導覽，完整本人操作介面於 M4-06 交付。詳情分開呈現原始回報、目前異常／執行版本、補件要求、私有照片、明確提交及歷史。原文保留空白、換行及 Unicode 字元表示；動作當時的角色與名稱以快照顯示。

補件要求及處置先檢視確認再送出。版本衝突保留本機原文，先重新讀取比較，再由使用者明確採用新資料。未知結果保留同一次內容與重送識別，GET、照片讀取及歷史收據均不能證明另一個 POST 沒有成功；原次重試不自動變更內容或識別。成功收據保留歷史版本，重新讀取目前資料後才允許新的命令。

私有照片以本人有效管理授權讀取，預覽結束、換案例或失去授權時撤銷暫存 URL；不提供公開網址。處置與照片不釋放人車、不完成任務。未確認策略顯示阻擋原因，合成策略清楚標示僅供隔離工程驗收。桌面／手機截圖只在關閉私有照片後保存。

## M4-05 管理確認與結案

ADMIN／DISPATCHER的「確認與結案」內分完成確認與訂單結案兩頁籤。先查看原完成紀錄、來源訂單版本，再以自己的行政確認版本及原文原因明確送出；確認不再次釋放人車。整單頁列出全部任務、true／未指定原旗標、完成及管理確認事實、整單占用與未解異常及目前策略阻擋；結案版本與行政確認版本分開，不將未指定當可略過。

已確認或已結案歷史與目前政策分別顯示；舊CLOSED沒有本階段紀錄時明示，沒有偽造actor／時間。未知結果保留原body／key及baseline，只能同次重試；GET與歷史不能替另一POST定案，CSRF更新後仍需明確重試。版本衝突保留原因、先讀取比較再明確採用；原次成功收據不直接覆蓋現在畫面，新命令前先fresh GET。跨頁籤／案例／導覽／登出以dirty／busy／未知狀態保護，失去授權清保護資料。無新增管理照片讀取權限或完整DRIVER表單，後者留M4-06。

## M4-06 本人完整操作

本人列表保留指派記錄語意，明確開啟本人任務才讀窄詳情；完成後顯示真完成witness，不依404或無占用猜完成。七動作各有明確檢視與送出：出發、照片、進度、異常、補件照片、補件提交、完成；執行與異常版本分開，完成不表示已管理確認或整單結案。提示停妥後操作。

未知結果保同一次不可變請求，只能明確原次重試；fresh GET為比較資料，不自動改原版本或清未知。原文／Unicode／decimal／時間保留，選照只屬目前合法範圍。手機單欄、觸控與鍵盤焦點、loading及錯誤提示納入真後端桌面／手機驗收。

背景與登出開始移除保護DOM及照片URL，停止新送出；普通登出失敗保同一component必要草稿／原次意圖。恢復不背景POST或復活舊URL，需明確重新讀取或重試。真authloss／換actor／離開清capability；404不保可重試rawpayload，只留未知結果說明。照片bytes不持久化、不改檔或提供公開網址。既有角色導覽及首次改密限制保留，DRIVER不查整單／管理API。

M4-07整合畫面驗收補強：≤680px的本人執行工作台操作列採全寬單欄，按鈕高度至少44px；舊FMS與桌面／分頁排列保留。真手機viewport驗證五個操作鈕均寬至少180px、高至少44px、接近整列且按原順序不重疊，保留全部原七種操作與錯誤復原流程。
