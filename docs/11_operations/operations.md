# 導入、維運與商業化｜Draft

先單家貨運公司試點，確認實際匿名進出口及國內案例、調度工作、司機手機使用方式與責任； UAT 以運輸閉環判定，不以功能清單數量判定。

維運依[公司 APP 規範](https://github.com/xk2022/xplore-kaleidoscope/blob/main/doc/04_engineering/app-operations-standard.md)：健康檢查、每日備份、異地保存、上線前還原演練及版本追蹤。照片保存、RPO/RTO、維運主責、每月成本上限及支援流程均待使用者定案。

商業方案候選：導入建置費＋月維運、依車隊／功能授權；實際價格與多租戶模式另案，不作收入承諾。
