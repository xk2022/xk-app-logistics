# TMS 領域與狀態｜已採用基準

依 [Q36–Q40](../98_decisions/2026-11-26-tms-dispatch.md)。訂單維持 OPEN＋ACCEPTED；TMS 擁有派工及有效占用，TOM 擁有任務來源及受理狀態，FMS 擁有行政來源。無跨模組 repository 存取。

| 操作 | 前提 | 結果 |
| --- | --- | --- |
| 指派 | 已受理、同單任務、前置就緒、無有效派工、授權與資源檢查通過 | ASSIGNED；建立排他占用及來源快照 |
| 撤派 | 當前有效 ASSIGNED，未出發 | REVOKED，原子釋放該次所有占用並留原因／人員／時間 |
| 改派 | 同上，指定新資源且重新驗證 | 舊紀錄 SUPERSEDED、新 ASSIGNED，原子交換占用 |
| 出發／完成／異常 | 後續 M4 | 本包不提供 |

派工紀錄狀態名稱為工程候選；撤派／改派不得改寫歷史；每個任務最多一組有效派工。改派任何步驟失敗，原派工與原占用完全保留。資源占用須在同一交易檢查並建立，司機、車輛及拖板不可被兩個有效派工同時占用；同一車輛不能同時作主車與拖板。FMS 管理狀態修改與占用需明確協調，不能靜默解除有效派工或使之失去行政資格；具體拒絕／異常政策如有未決衝突先回報。沒有預約、合載或假出發／假完成。
