# 核心業務流程｜Draft

1. 調度選擇進口、出口或國內類型與有效客戶，保存草稿。
2. 按類型補船務、貨櫃／貨物與必要路線任務；受理前檢查同單依賴無環及適用必填。
3. 正式受理後按前置條件安排分段任務；每任務同時最多一組有效派工。
4. 出發前撤派／改派保留歷史；出發後採異常流程。
5. 司機手機逐段回報與照片；作業完成且確認人車可離場後才釋放資源。
6. 後台行政確認獨立於釋放，必要任務及核定異常均處理後才整單結案。

狀態模型候選：訂單高階生命週期、訂單受理、任務及派工狀態分開；不可直接沿用舊文件互相矛盾的車輛狀態名稱。待定：可離場確認者、在途異常、預約時窗、合載、板車、獨立任務、照片規則及特殊進出口例外。
